# Capstone-Project - What-Should-I-Eat?
This project generates a meal recommendation!

The user has 3 options:
1. Find a meal based on their mood
2. Build their own 3 course meal
3. Randomly generate a meal

Option 1:
The user is asked:
- What they're in the mood for (healthy, comfort, fast food, fancy)
- What their budget is (£ - £££)
- Dietary requirements.
  
The program then generates a recommendation based on these answers.

Option 2:
The user is given 5 options for a starter, main and dessert.
these dishes all have seperate prices, and after choosing their 3
course meal, the user is shown the price of the meal they created and how 
much they should budget for it.

Option 3:
The user can have a meal be randomly generated, and keep generating a 
new meal until they are satisfied.
